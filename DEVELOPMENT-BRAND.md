# UI kit «Разработка»

Бренд-профиль для сервиса, где бизнес публикует задачу, получает отклики и выбирает проектную команду. Профиль расширяет исходный Cloudplus UI и не меняет API компонентов: React 19, shadcn/ui и Tailwind v4 остаются базовым контрактом.

## Быстрый старт

```tsx
import { ThemeProvider, TooltipProvider, Toaster } from '@cloudplus/ui'
import '@cloudplus/ui/styles.css'

<ThemeProvider
  defaultTheme="light"
  defaultBrand="development"
  defaultDensity="default"
  defaultAccent="neutral"
  defaultFont="onest"
>
  <TooltipProvider>
    <App />
    <Toaster />
  </TooltipProvider>
</ThemeProvider>
```

`BrandProfile` имеет значения `default | development`. Профиль можно переключить через `useTheme().setBrand('development')`. Провайдер ставит `data-brand="development"` на `<html>`. Для изолированного превью допустим тот же атрибут на контейнере.

## Визуальная система

- **Deep Blue** — доверие, компетентность, рабочая навигация и темный `AppRail`.
- **Sky / cyan** — активные состояния, фокус, прогресс и вторичные акценты.
- **Белые поверхности** — карточки предложений, бриф и сравнение команд.
- **Onest** — основной шрифт с кириллицей; системные sans-serif используются как fallback.
- **Крупные радиусы** — базовый `--radius: 1rem`; все shadcn-радиусы вычисляются из него.
- **Ясный CTA** — одно основное действие на экран: «Опубликовать задачу», затем «Выбрать».

Токены находятся в `packages/ui/src/tokens/development.css`. Они переопределяют канонические переменные shadcn (`--primary`, `--background`, `--card`, `--ring`, `--sidebar-*`) и существующие `--rail-*`, поэтому работают для всей библиотеки без форков компонентов.

## Семантика продукта

Основной сценарий:

1. Бизнес описывает задачу, сроки и бюджет.
2. Проверенные команды отправляют релевантные предложения.
3. Заказчик сравнивает специализацию, рейтинг и соответствие брифу.
4. Заказчик выбирает команду и переходит к обсуждению проекта.

Тексты интерфейса должны описывать действие и следующий результат. Предпочтительно: «Опубликовать задачу», «12 откликов», «Выбрать команду». Избегать абстрактных CTA вроде «Продолжить» без контекста.

## Демонстрация

Запустите витрину:

```bash
npm install
npm run dev:preview
```

Откройте страницу **Бренд «Разработка»** (`#development-brand`). Она показывает темный rail, проект, этапы публикации, список команд, match-рейтинг и готовность брифа. По умолчанию preview запускается с профилем `development`; `?brand=default` возвращает базовый профиль.

## Совместимость

- Существующие импорты из `@cloudplus/ui` не меняются.
- Все прежние пропсы компонентов сохранены.
- `defaultBrand` — необязательный проп `ThemeProvider`, по умолчанию `default`.
- Темная тема поддержана отдельным набором бренд-токенов.
- Цвета заданы в OKLCH и подключаются через токены, без хардкода в компонентах.
