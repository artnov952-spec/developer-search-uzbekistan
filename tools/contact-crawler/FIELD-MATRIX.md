## Правила UI

Панель показывает секцию критерия только если опубликованный снимок содержит хотя бы одно доказанное значение. Счетчики считаются по фактическим строкам снимка. Все выбранные критерии объединяются через AND, значения внутри одной секции через OR. Диапазоны скрыты, если соответствующего числового поля нет ни у одного кандидата.
