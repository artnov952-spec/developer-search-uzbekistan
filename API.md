# Справочник API — Cloudplus UI

Сгенерирован из исходников: `node packages/ui/scripts/gen-api.cjs`. **Править руками не нужно.**

Всё импортируется из корня пакета:

```tsx
import { Button, DataGrid, KanbanBoard } from '@cloudplus/ui'
import '@cloudplus/ui/styles.css'
```

|---|---|---|---|---|
| `label` | `React.ReactNode` | да | — | Подпись узла. |
| `icon` | `React.ReactNode` | — | — | Иконка слева от подписи. |
| `count` | `number` | — | — | Счётчик справа. |
| `level` | `number` | — | `0` | Уровень вложенности: задаёт отступ слева. |
| `active` | `boolean` | — | — | Текущий узел — подсвечивается. |
| `defaultExpanded` | `boolean` | — | `false` | Раскрыть узел при первом рендере. |
| `onSelect` | `() => void` | — | — | Клик по узлу. |
| `children` | `React.ReactNode` | — | — | Вложенные `TreeItem`. |
